# Ruby on Rails Blog Application

This is a simple Ruby on Rails application for managing blog posts.

## Features

*   Create new posts
*   Read existing posts
*   Update existing posts
*   Delete posts

## Post Structure

Each post consists of:

*   A `title` (string)
*   `content` (text)
